1. Copy .env.example to .env and paste your Groq key after GROQ_API_KEY=  (or skip this and paste the key in the app: Settings > Groq API key). Never share or commit .env
2. npm install
3. npm start   then open http://localhost:3000
Optional: save the rain/thunder mp3 as public/audio/rain-thunder.mp3 (otherwise a built-in synthesized rain plays).
